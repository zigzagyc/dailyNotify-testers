## 🐞 Jira 式 Bug 回報與任務管理 (GitHub Issues)

您可以在本倉庫的 **GitHub Issues** 頁面：
- **認領測試任務**：點擊 **Claim Test Task** 註冊您欲測試的 Task ID。
- **回報問題**：點擊 **Report a Bug** 提交問題與截圖，隨時查看開發團隊的修復進度。
